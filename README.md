# Leitor de HDs · The Youth

Programa que lê as torres e os SSDs da The Youth e manda o resultado para a planilha de controle.
Ele **só lê**: não apaga, não move, não renomeia e não grava nada nos discos.

Este repositório tem só as versões prontas do programa. Nada da planilha, das leituras ou das chaves fica aqui.

## Baixar

Última versão: **[Releases](../../releases/latest)**

- Windows 10 ou 11: `Leitor de HDs vX.Y (Windows).exe`
- Mac (macOS 11 ou mais novo): `Leitor de HDs vX.Y (Mac).zip`

Junto de cada versão vão os textos:

- `LEIA-ME`: como usar
- `INSTALAR_NO_MAC`: instalação passo a passo
- `CRIAR_O_ROBO`: criar o robô do Google (uma vez, com a conta da The Youth)

## Versão nova

O programa avisa sozinho quando sai uma versão nova aqui, com uma faixa amarela no alto da janela e o link para baixar. Ele não se troca sozinho.
